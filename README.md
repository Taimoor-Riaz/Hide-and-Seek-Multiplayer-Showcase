# Hide and Seek

**Online multiplayer mobile game · Unity · Photon Fusion · 2024**

A multiplayer take on the classic playground game. Each round, players are split into hiders and seekers: hiders blend into the environment, and seekers hunt them down before the timer runs out.

## What I built

- **Online multiplayer** with Photon Fusion, including room creation and player synchronization
- **Hider and seeker roles** with separate abilities and controls for each side
- **Round flow** covering role assignment, hiding time, the search phase, and results
- **Mobile controls and optimization** for smooth play on Android devices

## Tech stack

Unity · C# · Photon Fusion · Mobile
